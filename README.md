# Customer Purchase Behavior & Sales Insights Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional retail data to uncover patterns in purchasing habits, customer segments, product preferences, subscription behavior, and revenue generation. The analysis combines **Python**, **PostgreSQL**, and **Power BI** to transform raw data into actionable business insights and strategic recommendations.

The project follows an end-to-end data analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL-based business analysis, dashboard development, and report generation.

---

## 🎯 Objectives

* Understand customer purchasing patterns and spending behavior.
* Identify high-value customer segments.
* Analyze the impact of subscriptions, discounts, and promotions.
* Discover top-performing products and categories.
* Provide data-driven recommendations for business growth.

## 📂 Project Workflow

### 1. Data Collection & Loading

* Imported customer transaction dataset into Python.
* Examined dataset structure and data types.
* Performed initial exploration using descriptive statistics.

### 2. Data Cleaning

* Identified and handled missing values.
* Imputed missing review ratings using category-wise median values.
* Standardized column names using snake_case naming conventions.
* Removed redundant and unnecessary columns.
* Verified data consistency and integrity.

### 3. Feature Engineering

Created additional business-focused features such as:

* Age Groups
* Purchase Frequency Metrics
* Customer Segmentation Categories
* Revenue Contribution Measures

### 4. Exploratory Data Analysis (EDA)

Analyzed:

* Customer demographics
* Revenue distribution
* Product category performance
* Subscription behavior
* Discount utilization
* Purchase frequency trends
* Customer spending patterns

### 5. Database Integration

* Connected Python to PostgreSQL.
* Loaded cleaned dataset into PostgreSQL tables.
* Performed SQL-based business analysis.

### 6. SQL Business Analysis

Key business questions answered:

* Revenue by Gender
* Subscribers vs Non-Subscribers Analysis
* High-Spending Discount Users
* Top Rated Products
* Shipping Type Comparison
* Discount Dependency Analysis
* Customer Segmentation
* Revenue by Age Group
* Repeat Buyer Analysis
* Top Products by Category

### 7. Dashboard Development

Built an interactive Power BI dashboard featuring:

#### KPIs

* Total Revenue
* Total Orders
* Average Purchase Value
* Subscriber Revenue
* Repeat Customer Rate

#### Visualizations

* Revenue by Category
* Revenue by Gender
* Revenue by Age Group
* Subscription Status Analysis
* Top Products
* Customer Segments
* Discount Impact Analysis
* Purchase Frequency Analysis

#### Interactive Features

* Slicers & Filters
* Dynamic KPI Cards
* Drill-through Analysis
* Cross-filtering Visuals

### 8. Business Recommendations

Based on the analysis:

* Increase subscription adoption through exclusive benefits.
* Implement customer loyalty programs.
* Optimize discount strategies to improve profitability.
* Promote top-rated products.
* Target high-value customer segments with personalized marketing campaigns.
